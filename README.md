# 🧠 OpenClaw Local — AI System Controller (Local Clone)

OpenClaw Local ek **secure, owner-controlled AI system** hai jo  
**Telegram / Local CLI** ke through aapke **Linux PC ko control** karta hai —  
**purely local AI (Ollama)** ke saath, bina cloud dependency.

---

## 🚀 Features

✅ Local AI Brain (Ollama – qwen2.5-coder)  
✅ Natural Language → System Action  
✅ JSON-based safe decision system  
✅ Command execution (safe + filtered)  
✅ Strict App Launcher (firefox, terminal, editor, files)  
✅ Dangerous commands auto-blocked  
✅ Telegram Bot Interface  
✅ Local CLI Interface
